# PKIG — Konsola Zarządzania

Panel zarządczy dla kadry PKIG: zatwierdzanie godzin, projekty, arkusz płacowy, raporty.

## Hosting na GitHub Pages
1. Utwórz nowe repozytorium (np. `pkig-konsola`)
2. Wgraj plik `index.html`
3. Settings → Pages → Source: `main` branch → `/root`
4. Adres: `https://TWOJA-NAZWA.github.io/pkig-konsola/`

## Dostęp
Konsola przeznaczona dla: Zarząd, HR, Kierownicy, Zastępcy kierowników.
Docelowo dostęp kontrolowany przez Google OAuth (do wdrożenia).

## Konfiguracja API
URL backendu wpisany w `index.html` (zmienna `API_URL`).
